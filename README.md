# PlantCare - Plant Health Analyzer 🌱

A web-based application that helps identify plant diseases and provides care recommendations using your device's camera.

## Features

- 📷 Live camera plant scanning
- 🔍 Real-time plant disease detection
- 💡 Expert care recommendations
- 📊 Plant health tracking
- 🌐 Works entirely in browser

## How to Use

1. Open the app in your browser
2. Allow camera access when prompted
3. Point your camera at a plant leaf
4. Capture the image
5. View analysis results and recommendations

## API Integration

This app integrates with the Plant.id API for real plant identification. 
Get your free API key from [Plant.id](https://web.plant.id/api).

## Technologies Used

- HTML5, CSS3, JavaScript
- Plant.id API
- Camera API
- Responsive Design
